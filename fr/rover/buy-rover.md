# Acheter un rover RTK
Cette page liste quelques produits rover RTK compatibles avec le réseau Centipede-RTK.

*Cette liste n'est pas exhaustive, et la présence d'un produit sur cette liste n'implique aucune approbation de la part du projet Centipede-RTK.*

## [Natuition NavX](https://natuition.odoo.com/fr_FR/shop/n2168-navx-2678)
## [Sparkfun SparkPNT TX2](https://www.sparkfun.com/sparkpnt-tx2.html)
## [Sparkfun SparkPNT RTK Facet mosaic](https://www.sparkfun.com/sparkpnt-rtk-facet-mosaic.html)
## [ArduSimple RTK Smart Antenna](https://fr.ardusimple.com/product/rtk-smart-antenna/)
## [ArduSimple RTK Handheld 2 Mapping Kit](https://fr.ardusimple.com/product/rtk-handheld-surveyor-kit/)
## [ArduSimple RTK Portable 2](https://fr.ardusimple.com/product/simplertk2blite-bt-case-kit/)

:::warning
Pour les produits ArduSimple, privilégiez les modèles multibandes complets plutôt que ceux basés sur le module u-blox F9P.
:::
